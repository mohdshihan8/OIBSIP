# Calculator Web Application

## 📌 Project Overview
This is a responsive Calculator Web Application developed as **Level 2 - Task 1** for the **Oasis Infobyte Web Development & Designing Internship**.

## 🚀 Technologies Used
- HTML5
- CSS3
- JavaScript

## ✨ Features
- Basic arithmetic operations (+, -, ×, ÷)
- Decimal number support
- Clear (C) button
- Delete (DEL) button
- Division by zero error handling
- Responsive design
- CSS Grid layout
- JavaScript event listeners
