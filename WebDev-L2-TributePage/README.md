# Tribute Page – Dr. A.P.J. Abdul Kalam

## 📌 Project Overview
This project is a Tribute Page dedicated to Dr. A.P.J. Abdul Kalam, developed as **Level 2 - Task 2** for the **Oasis Infobyte Web Development & Designing Internship**.

## 🚀 Technologies Used
- HTML5
- CSS3
- JavaScript

## ✨ Features
- Responsive design
- Hero section with image
- Biography section
- Timeline of major achievements
- Inspirational quote
- Dark / Light mode toggle
- Smooth scroll animations
- Interactive timeline
- Google Fonts (Playfair Display & Poppins)
- Clean and modern UI
