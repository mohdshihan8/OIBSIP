# 📝 To-Do Web App

## 📌 Project Overview

The **To-Do Web App** is a modern task management application developed as **Level 2 - Task 3** for the **Oasis Infobyte Web Development & Designing Internship**.

This application helps users organize their daily tasks efficiently with features like task priorities, due dates, search, filters, progress tracking, and dark mode support.

---

## 🚀 Live Features

### ✅ Task Management
- Add new tasks
- Mark tasks as completed
- Undo completed tasks
- Edit existing tasks
- Delete tasks
- Clear all completed tasks

### ⭐ Advanced Features
- Priority levels:
  - High
  - Medium
  - Low
- Due date tracking
- Overdue task indication
- Search functionality
- Task filtering:
  - All Tasks
  - Pending Tasks
  - Completed Tasks
- Progress tracking bar
- Dark mode toggle
- Data persistence using Local Storage

### 📱 Responsive Design
- Fully responsive layout
- Works on desktop, tablet, and mobile devices

## 💾 Data Storage

The application uses **Browser Local Storage** to save tasks.

This allows users to:
- Refresh the page without losing tasks
- Close and reopen the browser while keeping data saved
