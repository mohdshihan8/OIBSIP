# 🔐 Login Authentication System

## 📌 Project Overview

This project is a **Login Authentication System** developed as **Level 2 - Task 4** for the **Oasis Infobyte Web Development & Designing Internship**.

The application provides a modern and responsive login interface where users can authenticate using email and password. After successful authentication, users are redirected to a protected dashboard. User sessions are managed using the browser's Local Storage.

---

## 🚀 Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Fonts
- Local Storage API

---

## ✨ Features

### 🔑 Login System

- Modern responsive login interface
- Email and password validation
- Floating label input design
- Password show/hide toggle
- Loading animation during authentication
- Success and error messages
- Animated background effects

### 🔒 Authentication Features

- Demo user login validation
- Local Storage based session management
- Protected dashboard access
- Automatic redirect when user is not logged in

### 📊 Dashboard

- Displays logged-in user details
- Welcome dashboard page
- Logout functionality
- Session removal after logout
